# Android publishing checklist

- [ ] Choose a final brand and verify Play Store availability.
- [ ] Set a unique reverse-domain application ID per app.
- [ ] Configure icons, screenshots, description, and store listing.
- [ ] Replace test AdMob IDs with production IDs.
- [ ] Configure Play Billing products and purchase verification.
- [ ] Complete Data safety, privacy policy, content rating, and ads declarations.
- [ ] Test on multiple Android versions and screen sizes.
- [ ] Keep upload keys outside Git.
- [ ] Run analysis, tests, and release App Bundle build.
- [ ] Use internal testing before production rollout.
